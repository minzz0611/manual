# 더존 ERP 디자인 시스템 (DOUZONE ERP Design System)

## 브랜드 개요
- **브랜드:** 더존(DOUZONE)
- **소개:** 기업·금융·커머스·헬스케어·공공 분야에 Work&Life 토털 솔루션을 제공하는 대한민국 대표 ICT 그룹
- **대상 제품:** 더존 ERP · OmniEsol
- **핵심 가치:** 연결(Connect) · 신뢰(Trust) · 혁신(Innovate)
- **브랜드 개성:** 전문성 · 미래지향 · AI
- **무드:** 넉넉한 여백의 깔끔한 엔터프라이즈 인터페이스
- **색상 방향:** 신뢰의 기반이 되는 블루/인디고, 혁신·AI를 나타내는 퍼플·마젠타 액센트
- **그라디언트:** 히어로·AI 순간에만 절제되게 사용
- **담긴 것:** 위 가치를 토큰 · 컴포넌트 · 전체 화면 재현물에 반영

## 콘텐츠 원칙 (CONTENT FUNDAMENTALS)
- **언어:** 모든 UI 텍스트는 한국어. 영문은 워드마크(DOUZONE)·제품명(OmniEsol)·슬로건에만.
- **표기:** 문장형(sentence case). 강조용 전체 대문자 미사용. 영문 조각도 문장형("AX and More").
- **어조:** 3인칭·중립적 전문 어조. 사용자에게 직접 말하지 않고 업무를 서술.
  - 권장: "비정상 지출 패턴 3건이 발견되었습니다"
  - 지양: "당신의 지출을 확인하세요"
- **액션 라벨:** 간결한 동사구 — "상세 보기", "전체 보기", "리포트 열기".
- **톤:** 신뢰감·차분함·유능함. 과장 없이 사실 진술. AI는 명령이 아닌 권고("검토를 권장합니다").
- **숫자:** 정확하고 정렬된 형태 — ₩ 8.42억, +12.4%.
- **길이:** 카드 제목 한글 4~10자 · 본문 1~2문장 · 뱃지 1~3자 또는 글리프.
- **이모지:** 사용 금지. 상태는 뱃지·시맨틱 색상으로 전달.

## 비주얼 파운데이션 (VISUAL FOUNDATIONS)

### 색상
- **메인:** 인디고 `#6053FF`
- **스펙트럼:** 사이언 `#00DCFF` → 블루 `#309AFF` → 인디고 `#6053FF` → 퍼플 `#A144D9` → 마젠타 `#E136FF` (각 색상 40~700 톤 램프)
- **뉴트럴:** 쿨 그레이 `#F4F6F9` → `#11141D`, 딥 네이비 `#0A0B20` (따뜻한 회색 미사용)
- **시맨틱:** 성공 그린 · 주의 앰버 · 위험 `#FC4C60` · 정보 `#00AAFF`
- **그라디언트:** `linear-gradient(90°, #00DCFF → #309AFF → #6053FF → #A144D9 → #E136FF)`. 히어로·강조형 카드 상단 바·아바타·AI 액센트에만. 전체 배경·본문 텍스트 미사용.

### 타이포그래피
- **폰트:** Pretendard 단일 패밀리(한글 + 영문 공용).
- **위계:** 서체 교체가 아닌 **굵기 대비**로 표현.
- **스케일:** Display 48/800 · H1 36/700 · H2 28/700 · H3 20/600 · Body 16/400 · Caption 13/400 · 컨트롤 14/600.
- **숫자:** 등폭(tabular) 사용.

### 스페이싱 & 그리드
- **기반:** 8px 시스템(미세 조정 4px). 토큰 xs4 · sm8 · md16 · lg24 · xl40 · 2xl64.
- **밀도:** 의도적으로 낮게 — 넉넉한 여백으로 엔터프라이즈적 안정감.
- **그리드:** 12컬럼 · 최대 컨테이너 1200px · 24px 거터/마진.

### 형태 (반경 · 카드 · 보더)
- **모서리 반경:** 컨트롤 8px · 뱃지 6px · 카드 12px · 히어로 16px · 필 999px.
- **카드:** 화이트 표면 · 0.5px 헤어라인 보더 · 12px 반경 · 20px 패딩 · `--shadow-sm`. 강조형은 상단 4px 그라디언트 바. 좌측 컬러 보더 액센트 미사용.
- **보더:** 헤어라인(0.5~1px) 쿨 그레이. 인터랙티브 컨트롤은 1.5px.

### 그림자
- **스타일:** 부드럽고 쿨 톤, 퍼짐 적음(`#171C24` 계열 rgba). sm/md/lg 3단계.
- **포커스 링:** 3px `--primary-100` 헤일로 / 에러 3px `--error-bg` 헤일로.
- **금지:** 강하거나 네온 그림자.

### 배경
- 평평한 쿨 그레이 페이지(`--neutral-50`) + 화이트 카드.
- 앱 UI에는 사진 배경·텍스처·반복 패턴 미사용.
- 풀블리드 이미지·그라디언트는 마케팅 히어로 맥락에만.

### 모션 & 인터랙션
- **모션:** 표준 이징 `cubic-bezier(0.2,0,0,1)`, 지속 120/180/260ms. 페이드·색 전환 중심. 바운스·무한 루프 없음. `prefers-reduced-motion` 존중.
- **호버:** 버튼 어두워짐(primary → `--primary-700`) 또는 틴트 채움(secondary → `--primary-50`, ghost → `--violet-50`). 내비는 틴트 배경. 확대 없음.
- **프레스:** 축소가 아닌 색 심화. 키보드 포커스 시 포커스 링.
- **투명도 & 블러:** 절제. 알파 오버레이보다 부드러운 틴트(40/50 단계). 밀도 높은 데이터 뷰에 글래스모피즘 미사용.

### 이미지 무드
- OmniEsol 마크는 쿨한 블루→퍼플 "연결된 노드" 모티프(라이트·그라디언트·다크 바탕).
- 미래지향적·깔끔·차가움. 브랜드 이미지는 블루-퍼플 계열 유지.

## 아이코노그래피 (ICONOGRAPHY)
- **현황:** 제공 소스에 아이콘 세트 없음(로고·제품 마크·슬로건 락업뿐). 내장 아이콘 폰트·SVG 라이브러리 부재.
- **대체(플래그):** UI 킷은 **Lucide**(CDN `0.544.0`) 사용 — 1.5px 스트로크 아웃라인. 임시 대체이므로 공식 세트 확보 시 교체.
- **사용:**
  - 아웃라인(스트로크) 아이콘, UI에서 16~20px.
  - 기본색 `--text-body` / `--text-muted`, 활성·강조 시 `--primary-500`.
  - 내비게이션은 텍스트 라벨과 함께, 단독 아이콘 버튼은 38px 히트 타깃.
  - 금지: 채움/듀오톤 아이콘 · 이모지 · 장식용 유니코드.
- **제품 마크:** OmniEsol 앱 아이콘(`assets/logos/omniesol_icon_0{1,2,3}.png`)은 라이트·그라디언트·다크 바탕 제공 — 라이트 UI엔 그라디언트, 다크 표면엔 다크 바탕.
